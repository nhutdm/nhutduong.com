## Hardware

- **MacBook Pro 2020** (i5 · 16 GB · 512 GB)
- **iPhone 15 Plus** (128 GB)
- **iPad** 11″ (128 GB) with the **Logitech Combo Touch** keyboard case
- **AirPods 4** with Active Noise Cancellation
- **Sofle RGB v2.1** — 58-key split ortholinear, per-key RGB, rotary encoder
- **Corne v4 Wireless** — 42-key columnar-staggered split, MX switches
- **UGREEN M751** mouse

</div>

- **Visual Studio Code** — Node.js
- **IntelliJ IDEA** — Java
- **iTerm2** — terminal
- **zsh** — shell
- **Dracula** — color theme
- **Rectangle** — window manager
- **Tailscale** — mesh VPN
- **Vivaldi** — browser

## Dev toolchain

- **TypeScript / Astro** for sites
- **Python** for agents and scripts
- **Cloudflare Workers + Wrangler** for deploys
- **Git + GitHub**
- **Obsidian** for notes

</div>

<div>

## This site

- **Astro 7**, built as a fully static site — no framework runtime, no analytics, no cookies
- **Tailwind CSS 4** with design tokens derived from the site's DESIGN.md
- **Source Serif 4, DM Sans, and IBM Plex Mono**, self-hosted via Fontsource
- **Cloudflare Workers** static assets for hosting
- The JavaScript on the page is the table of contents, view transitions, and the mobile menu
- Source: [github.com/nhutdm/nhutduong.com](https://github.com/nhutdm/nhutduong.com)
